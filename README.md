# mrtg-api-visualiser
Tool to visual data from the SingAREN mrtg-api API


# Running the tool
1. Clone the repository
2. Install dependencies using `pip install -r requirements.txt`
3. In terminal, run `streamlit run app.py`
4. Browse to `http://localhost:8501` in your web browser to view the visualisation tool if it does not open automatically
5. To stop the tool, press `Ctrl+C` in the terminal where the tool is running
